# Pigment
## A web app that can extract acrylic pigments and mix ratios for any photo or image

### Workflow
1. User can upload an image or point at a URL of a bitmap (JPEG, PNG, WEBP, GIF) 
2. System will apply a filter to image to reduce the # of colors (16 colors max)
3. System will then use a formula to determine the combinations of acrylic paint colors are required to make painting
4. The System will display the original image, the downsampled image w/ a key of the different ratios required for each color as well as a list of the base pigments required.
